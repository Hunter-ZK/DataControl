# DataControl / DataPortal

DataControl is a read-only data asset service portal for locating, understanding and tracing datasets, fields, metrics, standards and code values.

## Current phase: P1 backend complete candidate

P1 provides:
- Python/FastAPI backend
- SQLAlchemy domain model + Alembic baseline migration
- stable `asset_id` identity
- datasets, columns, catalogs, tags, standards, code tables/values, word roots, metrics, statistical systems, common SQL, changes and table lineage
- local development authentication boundary
- favorites, recent views, search history and audit records
- embedded SQLite FTS5 search index
- rich deterministic validation data
- responsive prototype for Windows/macOS desktop widths
- search-first home, full search result page, explicit back navigation and standalone Data Overview

It intentionally does **not** include metadata ingestion/governance, SQL execution, production SSO/LDAP, full Vue production UI, relation graph explorer or live Agent conversation.

## UI validation focus

1. Home is a search portal, not an asset dashboard.
2. Typing shows compact suggestions; submitting opens a dedicated search result page.
3. The search page has a stable two-column layout: filters + results. Search tips are not a third floating side panel.
4. Every non-home page has an explicit return control; the top bar also exposes back navigation.
5. The sidebar uses a lighter ocean-blue palette.
6. Layout adapts at 1280, 1050 and 760px breakpoints without nested `aside` selector collisions.
7. Data Overview is a separate page and reads P1 overview data from the backend.
