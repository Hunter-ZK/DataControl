# DataControl · Atlas UI 2.0 产品验收

开发分支：`feature/r0-r1-harness-autonomy-20261027`。本轮保留既有路由、API、Agent 模型选择以及只生成、不执行 SQL 的约束。UI 的主要改进针对 **视觉层级、信息密度与各类元数据正确的展示模型**。

## 视觉目标

- 避免整页纯白导致的视觉发散；在首页集中使用深蓝渐变和细网格，其他页面以浅蓝背景和有层次的高对比白色内容容器承载数据。
- 顶级功能图标约 27–36px，语义徽章约 46px，资产技术名使用清晰的等宽字体；不以大量 10–11px 文本承载主要信息。
- 搜索和资产目录使用不同信息组织：**搜索按类型分组**；**目录按树和子文件夹层级浏览**。
- 统计指标、词根、数据标准采用可比较的字典表；码表采用双栏主从布局；统计制度采用文档式清单。
- Agent 结果以对话为主；复杂证据从工作面板按需获取。所有真实任务阶段仍只能由实际工具调用推进，不展示模型隐藏思维。

## macOS 更新

```bash
git status --short
git switch feature/r0-r1-harness-autonomy-20261027
git pull --ff-only
bash start.sh
```

免费插件安装报错 `dsh: pnpm was not found` 时：新的 macOS 安装脚本将 `agent/dsh/node_modules/.bin` 放入 `PATH`，优先使用仓库中 pin 版本的 pnpm；如依然缺失，运行 `bash start.sh setup` 修复依赖后重试。插件兼容性仍需实机验证，缺少 pnpm 并不能解释其他兼容问题。
