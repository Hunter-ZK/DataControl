# DataControl 资产操作入口｜第一批交付与下一步边界

日期：2026-10-28（开发分支 PR #6，未合并 main）

## 设计依据
参考《DataControl 功能入口与资产页操作方案》：开放问题留在对话；外部批量材料留在工作台；已有资产操作就地执行。七类资产保持统一问 Agent 主按钮、常用操作、按导出/生成/分析/问 Agent 分组的“更多”菜单。复用 Atlas 蓝白设计令牌，不另建视觉体系。

## 本批代码已接入（不代表全部完成）
- 七类详情页使用统一的 `AssetOperationBar.vue`：TABLE、COLUMN、METRIC、CODE_TABLE、STANDARD、WORD_ROOT、STAT_SYSTEM。
- 现有 Ctrl+K / ⌘K 搜索面板自动列出当前资产可执行的操作；仍然可以检索其他资产。
- 数据集：复制表名、收藏/取消收藏、生成 DDL 草案（先预览）、导出字段字典 CSV、全字段查询草案、打开血缘、转入 Agent 解释或生成 SQL。
- 字段：复制字段名、打开所属表、打开字段血缘、按字段名检索、转 Agent。
- 指标：复制指标编码、来源数据集、导出当前语义定义 CSV、转 Agent 解释口径。
- 码表：复制码值、导出码值 CSV、CASE WHEN 草案预览、转 Agent。
- 标准/词根/统计制度：复制标识、已登记基础信息导出（标准和制度）、转 Agent；标准如有关联码表可跳转。
- 后端收藏接口已存在，本批仅补前端调用。

## 安全与真实性
- DDL/SELECT 只根据完整字段列表生成草案，字段类型与标识符需要通过安全检查；只预览/下载，绝不执行。
- 当前字段接口最多返回 500 行，不提供总数。为避免静默截断，页面仅在成功加载并返回 1–499 行时开放完整字段导出；恰好 500 行（即使可能完整）也暂时阻止导出。推荐后续补总数/分页接口，消除歧义。
- 尚无分区、生命周期与物理建表方言的完整元数据，所以草案明确缺项。不擅自添加 `dt` 分区字段。
- CSV 为 Excel 可打开的 UTF-8 BOM CSV，不等于方案要求的多工作表 XLSX；公式注入字符已转义。
- CASE WHEN 为替换 `source_column` 的 SQL 模板，使用前需人工核实码值类型/目标 SQL 方言。
- Agent 按现有路由进入完整会话，右侧抽屉尚未实现。现阶段不声称 11 个 Agent 动作均已在抽屉闭环。
- 全部操作只面向真实存在的接口和当前元数据。命名工作台尚未接通，不提供假按钮。

## 建议的下一批
1. 把导出所需元数据做成可靠的批量/计数契约；字段完整性及 XLSX 字典/口径卡，下载内容与分页总数核验。
2. 按用户提供的实际规范/样例建设命名工作台：输入→规则→复核→导出，保存词根库版本、分词结果、规则版本和人工修改轨迹。大模型分词不保证天然幂等；应缓存并人工确认不确定项。
3. 抽取 AgentView 的可复用会话与答案组件，再做右侧轻量抽屉；长任务切入完整工作区，并明确会话上下文与登录权限。
4. 指标 SQL 只调用现有语义编译器并后端验证必选过滤、时间可加性、维度白名单；不能由浏览器字符串拼接。
5. 反查（码表/标准/制度）优先复用已有 reference/agent-assets 读接口，经性能与权限检查后再判断是否增建专用接口。
6. 补充操作注册表完整性、下载字段数量、菜单键盘可达性、移动端和真实用户验收。
