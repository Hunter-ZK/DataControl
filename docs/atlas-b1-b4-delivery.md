# DataControl B1–B4｜增量交付与人工验收

实施分支：`feature/r0-r1-harness-autonomy-20261027`，PR #6 仍为 Draft，未合并 main。

## 本轮四笔独立提交

B1 **视觉框架**：重写统一的蓝白设计令牌及公共样式；首页缩减重复入口卡，强化资产搜索和近期工作；侧栏按工作空间／数据发现／数据理解组织。
B2 **资产页面**：资产检索页的清晰信息密度与列表，390px 小屏支持展开筛选；目录、数据集详情、字段详情和概览样式统一，字段标准与码表链接可直接跳转。
B3 **Agent 用户体验**：新增 `AgentTaskJourney`，以真实工具事件推动阶段状态（已完成／进行中／未触发／异常），优化三栏布局、输入区、回答卡；完善 answer-format、task-planning 与 query-workflow Skills。
B4 **数仓约定**：SQL 时间锚点采用 DataWorks/MaxCompute `'${dt}'`；不再对“最新”取数据表最大日期／分区；未经治理的“上期”先澄清；ETL 草案参数从 `'${bizdate}'` 统一为 `'${dt}'`，SQLite 保持 64 位整数行为并为其他数据库使用 BigInteger；更新相关契约断言。

## 已确认的范围调整

- 允许免费模型作为开发测试入口，目前模拟数据，不再额外建设免费模型/模拟数据隔离。
- 不开发 MAX_PT、自动维表 JOIN、跨源自动关联；优先使用已存在的 DWD/DWS/ADS 数据集，严格使用元数据字段。
- 不安排真实模型自动题库评分或 DuckDB Golden 比对；用户自行在前端验收。
- 只生成 SQL 与 DDL/ETL 草案，不执行生产数据库操作。
- 功能复杂度提升以标准化 Skills、真实任务阶段与回答体验为主。

## 人工验收任务（不运行自动评分）

1. 首页“贷款余额”：输入产生联想 → 检索资产 → 在同页看结果 → 点进真实资产详情。
2. 首页切换“向 DataAgent 提问”：跳转问数页面并携带问题。
3. 资产目录：选择业务主题，分页，打开 DWD/DWS/ADS 数据集；技术名清晰可见。
4. 全局搜索“region_code”：类别筛选、层级筛选、结果跳转；缩窄到 390px 后筛选按钮仍可用。
5. 数据集字段页：表头、中文名、技术名、数据类型易读；标准和码表可速览，字段详情可跳转关联。
6. Agent：“请找到贷款余额的指标口径并生成 SQL，使用 dt 调度参数”。检查生成 SQL 保留 `'${dt}'` 和来源依据，绝不返回虚构金额。
7. 连续问“改为按地区展示”，检查原指标是否保持；“只看广东省”，检查过滤条件是否依据已知码值。
8. 多步任务：“根据已登记的 DWD 表生成 DWS 加工草案，并补充非空/唯一性检查”，检查先说明步骤，再生成草案与缺失条件。
9. Agent 运行中检查阶段面板：只有对应真实 MCP 工具调用完成，才标记已完成；没有触发的项目显示“未触发”。
10. Free 模式：选择“免费模型测试”，使用公开模拟问题。无需设置环境变量；插件与 dsh 固定版本兼容尚未得到 Mac/Windows 实机确认，若不可用请提供日志。

## 当前尚未完成／刻意暂缓

- 真正由 dsh 输出的结构化计划与用户确认卡的双向协议；本轮 UI 是 **工具事件归纳的阶段进度**，而非模型内部私有计划。
- Token/成本、细粒度工具耗时与 Guard 集中审计存储；跨进程恢复。
- 全站全部旧页面、Pinia、OpenAPI 类型生成、Stylelint 零硬编码、Mac/Win 实际 UI 终验。
- MCP 逐用户 AuthzContext 下传和生产级权限。当前为本地模拟环境，真实业务接入前再优先解决。
- 复杂时间比较仍依赖有证据的月份模型；无规则时不可擅自生成前期/同期结果。
- 免费插件的固定版本与当前 dsh 的真实安装兼容；本轮未执行实机及自动测试。
