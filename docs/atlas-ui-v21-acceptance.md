# DataControl · Atlas UI 2.1（前端内容分区与 Agent 精修）

分支 `feature/r0-r1-harness-autonomy-20261027` / Draft PR #6。基于已经验收方向较好的 Atlas 2.0 小幅增量修改，不改后端接口、数仓语义与模型路由，不修改已确认的词根索引结构。

## 本轮变化

- 全局检索：外层按资产类型分组，内层每个资产单独的浅蓝边框子卡；每张子卡有 **名称/技术名**、**资产说明**、**来源及操作** 三级分区。交替使用白与浅蓝底色，hover 增强，键盘焦点可见。新增 **详细/精简** 切换，仅影响前端展示密度，保留名称和详情跳转，不篡改检索结果。
- 词根、业务指标、数据标准、码值明细：共享字典表的逐行交替底色、左侧轻描边、固定表头和悬停聚焦；词根字母检索与结构完全保留。码表主从目录、统计制度文档行也加入轻度交替背景。
- 资产目录：数据集列表交替底色、当前层级更明确，目录文件夹内容相互区分。
- DataAgent：工作台顶部显示来自真实 `status`、`loading`、`modelMode` 和 `taskTier` 的模式栏（包括服务未就绪状态），改造欢迎区轨道背景、任务能力标签、建议问题卡片；生成回答有 SQL/证据/真实工具步骤时新增 **结果工作区** 快捷入口，可直接切换右侧检查面板对应 Tab。真实调用进度不伪造。
- 回答：DataAgent 结果卡增加垂直视觉强调，标题区与正文区隔开；运行阶段在任务阶段组件内使用独立行底色，但状态仍由原真实工具事件驱动。
- 自动化：修复 Atlas 2.0 首页 Playwright 旧按钮选择器，增加检索详细/精简切换及词根字母筛选的 E2E 覆盖。

## 手工验收建议

1. 打开 `/search?q=贷款`：观察不同类型结果容器、同组不同记录的清晰边界；对比「详细／精简」；尝试目录树、DWD/DWS/ADS 筛选及点击资产。
2. 打开 `/word-roots`：验证两行及以上时明显交替底色，A–Z 过滤和关键词搜索正常；点击词根仍进原详情。
3. 打开 `/metrics`、`/standards`、`/code-tables`：对比行底色、主从码值预览、长文本截断/滚动。
4. 打开 `/catalog`：检查展开目录、数据集层级过滤、选中行和斑马纹。
5. 打开 `/agent`：查看未开始、加载中、已完成的视觉状态；真实任务返回 SQL 后点击「查看生成的 SQL」，检查右侧面板是否打开到 SQL Tab；对「查看数据依据」「查看任务步骤」执行相同操作。
6. 缩窄到 1024px 与 390px：检查检索记录在小屏下不横向溢出、Agent 结果快捷按钮换行、检查器右侧浮层能关闭。

## 保留边界

本次设计不是增加真实数仓执行或多表 JOIN，也不以 UI 的能力标签替代真实工具结果。免费模型仍用于模拟数据开发测试。GitHub 提交不等于本机视觉验收；如 CI 未通过，应先修复构建或回归断言后再宣称交付稳定。
