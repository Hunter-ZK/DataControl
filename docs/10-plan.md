# 10 · Phase plan

## P0 Foundation
Python architecture, stable identity, synthetic data, search spike, agent boundary, design baseline, runnable demo and verification.

## P1 Backend service layer
Complete asset/domain APIs, auth/application data, audit and full schema.

## P2 Product UI
Production Vue portal: dashboard, catalog, dataset/field detail, standards, word roots, metrics/statistical systems, personal center.

## P3 Advanced capabilities
Unified search, relationship explorer, dsh + Agent3 production intelligent Q&A.

## P4 Operations and release
Admin, security hardening, analytics, system status, full E2E/performance gates and deployment release.

Each phase is delivered once, verified by the user, then the next phase starts.
