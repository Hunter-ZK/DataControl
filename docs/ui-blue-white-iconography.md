# DataControl UI｜蓝白视觉与语义化资产图标

本次为前端单独提交，与可选免费模型插件提交分离，方便逐项回撤。

## 设计原则

- 主背景冷蓝白 `#F4F8FC`，卡片 `#FFFFFF`，边框 `#E2E8F0`；
  按钮／链接／焦点采用企业蓝 `#2563EB`，悬停 `#1D4ED8`。
- 资产类型图标由 `web/src/components/AssetIcon.vue` 统一管理。
  数据集靛蓝、字段蓝、标准绿、码表琥珀橙、基础参考紫、指标天蓝；
  色彩仅作为**资产类别标识**，不是生命周期状态。
- 保留现有卡片层级、圆角、胶囊和表格逻辑，不以“大面积渐变”掩盖内容。
  技术名使用等宽字体；减少旧页面不易读的小字号。
- 不改后端实体结构，不增加新的图标依赖（复用 lucide-vue-next）。

## 此提交涉及页面

- `AppShell.vue`：轻量蓝白侧栏、可折叠导航、资产类型语义图标、
  面包屑图标、Mac/Windows 全局搜索快捷键提示、帮助入口。
- `CatalogView.vue`：目录导航、数据集列表、层级／负责人／状态的图文表达，
  保留原有分页和后端查询参数。
- `SearchView.vue`：搜索联想、最佳匹配、结果列表中的类型图标；保留搜索逻辑。
- `DatasetDetailView.vue`：字段类型图标、标准／码表预览按钮，
  右侧 Drawer 基于现有 `/code-tables/{no}` 与 `/data-standards` 接口显示真实数据。
  预览有码值清单与“查看完整资产详情”路径；不凭空推测关联。
- `HomeView.vue`、`OverviewView.vue`、`ReferenceListView.vue`：
  快速入口、搜索结果、概览指标和参考资产类型图标统一。

## Mac 人工验收重点

1. 首页、导航、概览、搜索及目录的蓝白配色一致；查看不同资产类型图标能否一眼识别。
2. 桌面侧边栏“收起／展开”有效；Mac `⌘K` 弹出快速搜索，Windows `Ctrl+K`。
3. 资产目录主题切换与分页仍能查询，不仅是静态界面。
4. 数据集详情 → 字段信息 → 点击“标准编号”或“码表编号”，
   右侧抽屉能显示数据、码值和完整详情入口。
5. 390px 窄屏下仍能打开导航抽屉、搜索、字段列表。
6. 智能问数、关联图、码表完整详情的原有功能未受样式改造影响。
